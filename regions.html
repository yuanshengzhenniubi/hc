Seven Nations · 七国

把远方的风，
装进一张地图

每个国家都有自己的答案：蒙德说自由，璃月说契约，稻妻说永恒，须弥说智慧，枫丹说舞台，纳塔说勇气。地图不是任务清单，是一封封写给远方的信。

02
风与自由

蒙德

Mondstadt

风车、蒲公英、诗与酒。这里的风不催人赶路，只提醒你偶尔抬头。

喜欢在风起地的大树下坐着，看风把草叶吹成一片绿色的海。
推荐：风起地 / 天使的馈赠01
岩与契约

璃月

Liyue

山海之间的港口，灯火一层层亮起来。契约让陌生人也能放心把后背交给彼此。

海灯节的人潮里，最动人的不是烟花，是每个人都抬头看着同一片天。
推荐：璃月港 / 庆云顶02
雷与永恒

稻妻

Inazuma

樱花落在鸟居上，雷声从海面滚过来。永恒不是一个答案，而是一场漫长的追问。

在神樱大祓之后，我忽然觉得，所谓永恒，也许是把此刻认真留住。
推荐：鸣神大社 / 神里屋敷03
草与智慧

须弥

Sumeru

雨林把天空遮成碎片，书页在风里翻动。知识不是标准答案，而是允许你继续提问。

在净善宫外绕了很久，最后记住的是一句：先看见，再判断。
推荐：净善宫 / 桓那兰那04
水与舞台

枫丹

Fontaine

喷泉、歌剧院、潮汐一样的掌声。每个人都在表演，也都在寻找谢幕后真实的自己。

看完一场歌剧，沿着水边走回住处，觉得日常也值得一场认真的谢幕。
推荐：欧庇克莱歌剧院 / 白露区05
火与勇气

纳塔

Natlan

火山、部族、竞速与战歌。火焰不是破坏，是把还在前行的人照亮。

如果有一天走到纳塔，我想先看一场夜里的火，再决定下一站去哪。
推荐：圣火竞技场 / 火山口06
一条不赶时间的路线 蒙德 → 璃月 → 稻妻 → 须弥 → 枫丹 → 纳塔
